# anchorlist: virtual list with stable scroll anchoring for React, Vue and Svelte

**anchorlist** is a tiny virtual list (virtualized list / windowing library) with stable scroll
anchoring, built for chat lists without scroll jump, reverse infinite scroll, infinite feeds,
dynamic item heights, masonry and grid layouts.

> **Status: pre-release.** This package is a placeholder; the first usable version is planned as v0.1.

## Install

```sh
npm install anchorlist
```

- Virtual list for infinite feeds: https://saranbalaji1408.github.io/anchorlist/guide/feed

## Packages

- `anchorlist` re-exports `@anchorlist/core` and `@anchorlist/react`.
- `@anchorlist/core` is the framework-agnostic engine with zero dependencies.
- `@anchorlist/react` provides React 18 / 19 bindings.
